ScriptBlocker

Turn JavaScript off everywhere, or only on the websites you choose.

A Safari extension for Mac, iPhone, and iPad.

  • One switch per website Turn JavaScript off for the website you’re on, right from Safari’s toolbar or page menu.
  • Or every website at once Block JavaScript everywhere, and turn it back on whenever you need it.
  • Inline scripts too Blocks every script a website loads, plus the scripts written into the page itself. Pages that offer a no-JavaScript version show it instead.
  • Stays on your device No account, no analytics, no tracking. Your list of blocked websites is never sent anywhere.
