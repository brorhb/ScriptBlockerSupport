Privacy Policy

Last updated: November 5, 2026

Overview

ScriptBlocker does not collect, transmit, or share any data. Everything it needs stays on your device.

Data stored on your device

ScriptBlocker stores two settings in Safari's storage for extensions, on the device where you set them:

  • Whether JavaScript is blocked on every website
  • The list of websites where you've blocked JavaScript

These settings are not synced to iCloud or any other service. Deleting ScriptBlocker removes them.

Website access

To block scripts, ScriptBlocker needs permission to work on all websites. It uses this access only to:

  • Read the address of the current tab, to show which website you're on and whether it's blocked
  • Block script files and set a Content Security Policy on the websites you've blocked
  • Show a page's no-JavaScript content (<noscript>) when its scripts are blocked

ScriptBlocker does not read form fields, passwords, or page contents, and keeps no browsing history.

Network requests

ScriptBlocker makes no network requests of its own.

Analytics and tracking

ScriptBlocker contains no analytics, crash reporting, advertising SDKs, or any form of user tracking.

Third-party SDKs

ScriptBlocker uses only Apple's built-in frameworks and Safari's extension APIs. No third-party code or SDKs are included.

Children

ScriptBlocker does not collect data from anyone, including children.

Changes to this policy
